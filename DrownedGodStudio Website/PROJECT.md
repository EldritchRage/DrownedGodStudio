# Drowned God Studio

## Goal

Create a premium tattoo studio website.

The website is NOT the product.

The Ninth Tide mobile app is the product.

The website exists to:

- Establish trust
- Showcase portfolio
- Explain the tattoo experience
- Direct visitors to download The Ninth Tide
- Satisfy Stripe business requirements
